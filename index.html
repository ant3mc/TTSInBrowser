Программа для синтеза речи в браузерах (Chrome, Edge и др.).

Поддерживает форматы: TXT, HTML

Функции:

  • Регулировка скорости и громкости
  • Навигация по фрагментам
  • Подсветка текущего фрагмента
  • Поддержка пользовательского словаря замен
  • Управление с клавиатуры
  • Сохранение позиции для последних 20 файлов

Горячие клавиши:

  • Пробел: Пуск/Пауза (работает на кнопках и основном экране, но не в полях ввода)
  • Alt+K, Alt+Л, K, Л: Пуск/Пауза (работают везде)
  • ←/→: Навигация по фрагментам
  • Alt+← / Alt+→: Навигация по фрагментам (глобально)
  • , / . (а также < / >, б / ю, Б / Ю — с Shift и без): Скорость речи локально (медленнее / быстрее)
  • ↑ / ↓: Прокрутка текста на одну строку вверх / вниз (ручная прокрутка отключает авто-центрирование до смены основного фрагмента)
  • Alt+, / Alt+. (в любой раскладке, с Shift и без): Скорость речи глобально
  • 9 / 0: Громкость (9 — тише, 0 — громче)
  • j / l: Навигация внутри текущего фрагмента (субфрагменты; j — назад, l — вперёд)
  • Alt+J / Alt+L: Субфрагменты глобально
  • Alt+S: Сохранить текущую позицию (только для файлов)
  • Alt+B: Мгновенная остановка озвучки (работает везде)
  • Alt++ / Alt+-: Размер шрифта
  • Alt+F / Alt+А: Скрыть/показать панель управления (имитация полноэкранного режима)
  • Tab и Shift+Tab: Навигация по элементам
  • Escape: Закрыть модальное окно, вернуться в меню или (в режиме ввода текста) переключиться в режим озвучки

Управление касаниями (на экране с текстом):

  • Одиночное касание в центр экрана — пауза / возобновление воспроизведения.
  • Двойное касание в центр экрана — скрыть / показать панель управления (полноэкранный режим).

Важно для мобильных устройств:

  • В мобильном Edge сразу после загрузки (или перезагрузки) приложения нужно активировать голоса. Для этого выделите слово в названии приложения и вызовите встроенную функцию браузера «Прочесть вслух». После этого можно выбирать голоса в самом приложении.
  • Чтобы озвучка продолжалась на мобильных устройствах с выключенным экраном, может потребоваться отключить энергосбережение у браузера.

Выбор голоса

Если голосов 0: на мобильных устройствах (особенно в Edge) движок синтеза речи может требовать ручной активации. Попробуйте:
  • В мобильном Edge: меню браузера → «Чтение вслух» → выделите любое слово → вернитесь в приложение и нажмите «Обновить голоса».
  • В Chrome: убедитесь, что в системе Android установлен и выбран движок Google TTS (Настройки → Система → Языки и ввод → Синтез речи).
  • Проверьте подключение к интернету — некоторые голоса загружаются из сети.
